# JobZen🔍

An Information Retrieval (IR) based Job Search Engine built in **Python using Google Colab**. The system allows users to search job postings using keywords and Boolean queries while ranking results using the **TF-IDF algorithm**.

## Features

* Search job postings with keywords
* Boolean query support (AND / OR)
* TF-IDF based ranking
* Inverted Index for fast retrieval
* Text preprocessing with NLTK
* Relevant snippet generation
* Interactive Gradio web interface

## Tech Stack

* Python
* Google Colab
* Pandas
* NumPy
* NLTK
* Gradio

## Information Retrieval Techniques

* Inverted Index
* Boolean Retrieval Model
* TF-IDF Ranking
* Tokenization
* Stop-word Removal
* Stemming

## Project Workflow

```text
User Query
    ↓
Query Processing
    ↓
Text Preprocessing
    ↓
Inverted Index Search
    ↓
Document Retrieval
    ↓
TF-IDF Ranking
    ↓
Result Display
```

## Running the Project

1. Open the notebook in Google Colab.
2. Upload/connect the required datasets.
3. Run all notebook cells.
4. Launch the Gradio interface.
5. Start searching for jobs.
